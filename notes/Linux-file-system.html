Linux File System Structure

Linux organizes everything under a single directory tree that begins with the root directory (/). Unlike Windows, which uses drive letters such as C: or D:, Linux stores every file and directory under this single hierarchy. Understanding these directories is essential for system administration and troubleshooting.

Linux Directory Tree

Root Directory (/)

The / directory is the highest level of the Linux file system. Every other directory is located somewhere beneath it. 

/
├── bin
├── boot
├── dev
├── etc
├── home
├── lib
├── media
├── mnt
├── opt
├── proc
├── root
├── run
├── sbin
├── sys
├── tmp
├── usr
└── var

/bin — Essential User Commands

The /bin directory contains essential command-line utilities required for basic system operation. These commands are available to all users.

Command Purpose
ls List files and directories.
cp Copy files.
mv Move or rename files.
cat Display file contents.

/sbin — System Binaries

Contains administrative commands mainly used by the system administrator (root). These commands are responsible for system maintenance and configuration. 

fdisk
reboot
iptables
fsck

/etc — Configuration Files

Stores system-wide configuration files used by the operating system and installed applications.

File Description
/etc/passwd User account information.
/etc/hosts Hostname mappings.
/etc/fstab Filesystem mount configuration.

/home — User Home Directories

Every regular user has a personal directory inside /home. Personal files such as documents, downloads, and projects are stored here. 

/home
├── alice
├── bob
└── john

/root — Root User Home

The administrator (root) has a separate home directory located at /root. Only the root user normally has access to this directory.

/var — Variable Data

Stores files that change frequently while the system is running.

Directory Purpose
/var/log System logs.
/var/cache Application cache.
/var/spool Queued print jobs and mail.

/tmp — Temporary Files

Applications store temporary files in this directory. Most Linux distributions automatically remove these files after a reboot.

/usr — User Programs

Contains most user applications, libraries, documentation, and shared resources. It is one of the largest directories in Linux.

Directory Purpose
/usr/bin User applications.
/usr/lib Shared libraries.
/usr/share Documentation, icons, fonts.

/lib and /lib64 — Shared Libraries

These directories contain shared libraries required by system programs. They are similar to DLL files in Microsoft Windows.

/dev — Device Files

Linux represents hardware devices as files. Applications communicate with hardware by reading from and writing to these device files. 

/dev/sda      Hard disk
/dev/sdb      Second disk
/dev/tty      Terminal
/dev/null     Discards data

/proc — Process Information

A virtual filesystem that provides information about running processes and kernel status. The files are generated dynamically by the kernel. 

/proc/cpuinfo
/proc/meminfo
/proc/version

/sys — System Information

Provides information about devices, drivers, and kernel components. System administrators often use this directory to inspect hardware.

/boot — Boot Files

Contains everything required to start the Linux operating system. 

Kernel
GRUB Bootloader
Initial RAM Disk (initramfs)

/mnt — Mount Point

Used as a temporary location for manually mounting storage devices. 

sudo mount /dev/sdb1 /mnt

/media — Removable Devices

Automatically mounted USB drives, DVDs, and external storage devices appear here. 

/media/username/USB

/opt — Optional Software

Third-party software packages are commonly installed inside this directory. 

/opt/google
/opt/zoom

/run — Runtime Information

Stores temporary runtime information such as process IDs, sockets, and lock files. Its contents are recreated after every reboot.

Important Linux Concepts

Inode

An inode stores metadata about a file, including its size, owner, permissions, and timestamps. The filename itself is not stored inside the inode. 

Inode contains:
• Owner
• Permissions
• Size
• Timestamps
• Disk block locations

File Permissions

Linux controls file access using read, write, and execute permissions.

Permission Description
r Read
w Write
x Execute 
chmod 755 script.sh
chmod 644 notes.txt

Mounting

Mounting is the process of attaching a storage device to a directory within the Linux filesystem. After mounting, the files on that device become accessible. 

sudo mount /dev/sdb1 /mnt

Journaling

Modern Linux filesystems such as ext4 maintain a journal that records filesystem changes before they are written to disk. This greatly improves recovery after unexpected shutdowns or power failures.
