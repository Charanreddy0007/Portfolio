How an ISP Gives Internet to Your Router

Ever wondered what happens the moment your router powers on? Within seconds, your ISP assigns it a public IP address, your router creates a private network, and every device in your home can access the Internet.

Step 1 — Router Requests Internet

When your router powers on, it knows nothing about the Internet. It doesn't have an IP address or know where to send traffic. The first thing it does is ask your ISP for network information.

   │
   │ "Hello, I need Internet."
   ▼
ISP

The ISP replies:

"Your public IP is 73.44.81.210"

This process uses the Dynamic Host Configuration Protocol (DHCP).

What is DHCP?

DHCP automatically assigns network settings to devices. Without DHCP, every device would need to be configured manually.

  • Public IP Address
  • Subnet Mask
  • Default Gateway
  • DNS Server

How the ISP Assigns an IP

The ISP owns a large pool of public IP addresses. Whenever a customer connects, one available address is leased to the router.

Step 2 — Router Creates a Local Network

Once connected to the Internet, your router becomes a miniature ISP for your home. Instead of assigning public IPs, it creates private IP addresses for every device.

How Do Multiple Devices Share One Public IP?

The answer is Network Address Translation (NAT).

Whenever one of your devices accesses the Internet, the router replaces its private IP with the router's public IP.

Before NAT

192.168.1.2 ─────────► google.com

After NAT

98.44.120.8 ─────────► google.com

Google never sees your phone's private address. It only sees your router's public IP.

NAT Translation Table

Internal Device Public Mapping
192.168.1.2 98.44.120.8:5001
192.168.1.3 98.44.120.8:5002

When the response comes back from Google, the router checks this table and forwards the packet to the correct device.

Why Private IP Addresses Exist

IPv4 supports approximately 4.3 billion unique addresses. That isn't enough for every phone, laptop, TV, server, and IoT device on Earth.

Instead of giving every device a public IP, routers use NAT so multiple devices can share a single public address.

Private IPv4 Ranges

10.0.0.0      - 10.255.255.255

172.16.0.0    - 172.31.255.255

192.168.0.0   - 192.168.255.255

Because these addresses are private, millions of homes can safely use the same IP. 

Your Home
192.168.1.2

Someone Else's Home
192.168.1.2

This works because private networks are isolated from one another.

Key Takeaways

  • The ISP gives your router a public IP using DHCP.
  • Your router creates a private network inside your home.
  • Every connected device receives its own private IP.
  • NAT allows multiple devices to share a single public IP.
  • Private IP addresses can be reused in millions of different networks.
