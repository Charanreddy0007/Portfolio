Essential Linux Commands Every Developer Should Know

Whether you're developing software, managing servers, or learning cybersecurity, the Linux terminal is one of the most powerful tools you'll use. This guide covers the most common Linux commands grouped by category, making it an easy reference for everyday tasks.

Basic Commands

These commands help you navigate the terminal and inspect your current working environment.

Command Description
pwd Display the current working directory.
ls List files and directories.
cd Change the current directory.
clear Clear the terminal screen.
history Display previously executed commands.
man Open the manual page for a command.

File & Directory Management

Linux provides powerful commands for creating, copying, moving, editing, and deleting files and directories.

Command Description
mkdir Create a new directory.
rmdir Remove an empty directory.
rm Delete a file.
rm -rf Forcefully delete a directory and all its contents.
cp Copy files or directories.
mv Move or rename files.
touch Create an empty file.
cat Display the contents of a file.
nano Edit files using the Nano editor.

Searching & Viewing Files

Searching for files or specific text is one of the most common tasks in Linux. These commands make locating and viewing information much easier.

Command Description
find Search for files and directories.
grep Search for text inside files.
locate Quickly locate files using a database.
less View large text files page by page.
head Display the first 10 lines of a file.
tail Display the last 10 lines of a file.

User & Permission Management

Linux is a multi-user operating system. These commands help you manage users, groups, ownership, and file permissions.

Command Description
whoami Display the current logged-in user.
id Display user and group information.
adduser Create a new user account.
passwd Change a user's password.
chmod Modify file or directory permissions.
chown Change file ownership.
sudo Run commands with administrator privileges.

Package Management (APT)

Ubuntu and Debian use the APT package manager to install, update, and remove software packages.

Command Description
apt update Refresh the package list.
apt upgrade Upgrade installed packages.
apt install Install a package.
apt remove Remove an installed package.
apt search Search for available packages.

Network Commands

These commands are useful for checking network connectivity, viewing interfaces, and troubleshooting networking issues.

Command Description
ifconfig Display network interfaces.
ip a Display IP addresses.
ping Test network connectivity.
netstat -tulnp Show open ports and active network connections.
ss Display socket statistics.
route Display the routing table.
arp -a Display the ARP table.

Process Management

Every running application is a process. These commands help monitor, manage, and terminate running processes.

Command Description
ps Display running processes.
top View live system processes.
htop Interactive process viewer.
kill Terminate a process using its PID.
killall Terminate processes by name.
bg Resume a suspended process in the background.
fg Bring a background process to the foreground.

System Information

Use these commands to inspect your Linux system, hardware, memory usage, and disk space.

Command Description
uname -a Display kernel and system information.
hostname Show the system hostname.
uptime Display system uptime.
df -h Show disk usage.
free -h Display memory usage.
lsusb List connected USB devices.
lspci List PCI devices.

Archiving & Compression

These commands help compress files, create archives, and extract compressed data.

Command Description
tar -cvf Create a TAR archive.
tar -xvf Extract a TAR archive.
gzip Compress files using Gzip.
gunzip Decompress Gzip files.
zip Create ZIP archives.
unzip Extract ZIP archives.

Summary

These commands form the foundation of everyday Linux usage. Whether you're working in development, DevOps, cybersecurity, or system administration, mastering these commands will make navigating the terminal and managing Linux systems significantly easier. As you gain experience, these commands will become part of your daily workflow.
