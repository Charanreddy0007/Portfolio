MySQL Database Fundamentals

MySQL is a relational database management system (RDBMS) used to store, organize, and retrieve data efficiently. Before storing data, a database must be created, selected, and structured into tables.

Creating a Database

The CREATE DATABASE statement creates a new database with the specified name. 

CREATE DATABASE databaseName;

Once executed successfully, MySQL creates an empty database ready for storing tables.

Deleting a Database

The DROP DATABASE statement permanently removes an entire database, including every table and all stored data. 

DROP DATABASE databaseName;

Use this command carefully because deleted databases cannot be recovered.

Selecting a Database

Before creating tables or inserting records, you must select the database you want to work with. 

USE databaseName;

Creating a Table

Tables store data in rows and columns. Every column has a name, data type, and optional constraints. 

CREATE TABLE table_name (

    column_name1 datatype constraint,

    column_name2 datatype constraint,

    column_name3 datatype constraint

);

Example

CREATE TABLE student (

    id INT PRIMARY KEY,

    name VARCHAR(50),

    age INT NOT NULL

);

Keys

Keys uniquely identify records and establish relationships between tables.

Primary Key

A Primary Key uniquely identifies every row in a table. Only one primary key can exist in a table, and it cannot contain NULL values.

Property Description

Foreign Key

A Foreign Key links one table to another by referencing the primary key of another table.

Unlike primary keys, foreign keys may contain duplicate values and NULL values.

Example

    order_id INT PRIMARY KEY,

    customer_id INT,

    FOREIGN KEY(customer_id)

SQL clauses are used to filter, sort, and limit the records returned by a query. They allow you to retrieve only the data you need from a table.

WHERE Clause

The WHERE clause filters rows based on a specified condition. Only the rows that satisfy the condition are returned.

Syntax

SELECT * FROM table_name WHERE condition;

Examples

SELECT * FROM student WHERE marks > 80; SELECT * FROM student WHERE city = "Hyderabad";

Example Output

Roll No Name Marks City
1 Ajay 92 Hyderabad
3 Karan 85 Hyderabad

Only the rows matching the specified condition are displayed.

LIMIT Clause

The LIMIT clause restricts the number of rows returned by a query. It is commonly used when displaying only the first few records.

Syntax

SELECT * FROM table_name LIMIT number;

Example

SELECT * FROM student LIMIT 3;

The query returns only the first three rows from the table.

LIMIT with WHERE

The LIMIT clause can also be combined with the WHERE clause. 

SELECT * FROM student WHERE marks > 85 LIMIT 3;

Example Result

Roll No Name Marks
1 Ajay 95
5 Rahul 91
8 Vijay 89

WHERE vs LIMIT

Clause Purpose
WHERE Filters rows based on a condition.
LIMIT Restricts the number of returned rows.

Combining WHERE and LIMIT

Both clauses are frequently used together to retrieve a small number of records that satisfy a particular condition. 

SELECT * FROM student WHERE city = "Hyderabad" LIMIT 5;

This query returns a maximum of five students whose city is Hyderabad.

Summary

Clause Description
WHERE Filters rows using conditions.
LIMIT Limits the number of returned rows.
WHERE + LIMIT Filters the data first, then limits the output.

ORDER BY Clause

The ORDER BY clause is used to sort the rows returned by a query. By default, MySQL sorts the data in ascending (ASC) order, but it can also sort in descending (DESC) order.

Syntax

SELECT *
FROM table_name
ORDER BY column_name ASC;

The ASC keyword sorts the records from the smallest value to the largest value. If ASC is omitted, MySQL uses ascending order by default.

Ascending Order (ASC)

SELECT *
FROM student
ORDER BY marks ASC;

Example Output

Roll No Name Marks
4 John 62
2 Vijay 75
1 Ajay 89
3 Karan 95

The records are arranged from the lowest marks to the highest marks.

Descending Order (DESC)

Use the DESC keyword to sort the records from highest to lowest. 

SELECT *
FROM student
ORDER BY marks DESC;

Example Output

Roll No Name Marks
3 Karan 95
1 Ajay 89
2 Vijay 75
4 John 62

Sorting by Multiple Columns

MySQL can sort data using more than one column. If two rows have the same value in the first column, the second column is used for sorting. 

SELECT *
FROM student
ORDER BY city ASC, marks DESC;

The rows are first grouped alphabetically by city. Within each city, students are sorted by their marks in descending order.

ORDER BY with WHERE

The ORDER BY clause is commonly used together with the WHERE clause. 

SELECT *
FROM student
WHERE city = "Hyderabad"
ORDER BY marks DESC;

This query returns only students from Hyderabad and displays them from the highest marks to the lowest.

ORDER BY with LIMIT

The ORDER BY clause is often combined with LIMIT to retrieve the top records. 

SELECT *
FROM student
ORDER BY marks DESC
LIMIT 5;

This query returns the five students with the highest marks.

Common Uses

Query Purpose
ORDER BY id ASC Sort by ID from smallest to largest.
ORDER BY marks DESC Sort by highest marks first.
ORDER BY name ASC Sort names alphabetically.
ORDER BY salary DESC LIMIT 10 Display the top 10 highest salaries.

Summary

Keyword Description

GROUP BY Clause

The GROUP BY clause groups rows that contain the same values into summary rows. It is commonly used together with Aggregate Functions such as COUNT(), SUM(), AVG(), MIN(), and MAX().

Syntax

SELECT column_name,
aggregate_function(column_name)
FROM table_name
GROUP BY column_name;

Example

Find the highest marks scored in each city. 

SELECT city,
MAX(marks)
FROM student
GROUP BY city;

Example Output

City Highest Marks
Hyderabad 98
Mumbai 91
Delhi 94

Students are grouped by city, and the maximum marks are calculated for each group.

HAVING Clause

The HAVING clause filters grouped data. Unlike the WHERE clause, which filters rows before grouping, HAVING filters the groups after the aggregation has been performed.

Syntax

SELECT column_name,
aggregate_function(column_name)
FROM table_name
GROUP BY column_name
HAVING condition;

Example

Display cities where the highest marks are greater than 90. 

SELECT city,
COUNT(rollno)
FROM student
GROUP BY city
HAVING MAX(marks) > 90;

Example Output

City Students
Hyderabad 8
Delhi 5

WHERE vs HAVING

WHERE HAVING
Filters rows. Filters groups.
Runs before GROUP BY. Runs after GROUP BY.
Cannot use aggregate functions. Can use aggregate functions.

SQL Operators

Operators are used inside the WHERE clause to compare values or combine multiple conditions.

AND Operator

Returns records only when both conditions are true. 

SELECT *
FROM student
WHERE marks > 80
AND city = "Hyderabad";

OR Operator

Returns records when either condition is true. 

SELECT *
FROM student
WHERE marks > 80
OR city = "Hyderabad";

BETWEEN Operator

Selects values within a specified range. 

SELECT *
FROM student
WHERE marks BETWEEN 80 AND 90;

IN Operator

Checks whether a value exists in a given list. 

SELECT *
FROM student
WHERE city IN ("Mumbai","Delhi");

NOT Operator

Reverses a condition. 

SELECT *
FROM student
WHERE city NOT IN ("Mumbai","Delhi");

Operator Summary

Operator Description
AND Both conditions must be true.
OR At least one condition must be true.
BETWEEN Select values within a range.
IN Match values from a list.
NOT Reverse a condition.

Updating and Deleting Data

Once data has been inserted into a table, MySQL provides statements to modify, delete, and automatically maintain relationships between tables. These operations are commonly used when maintaining databases.

UPDATE Statement

The UPDATE statement modifies existing records in a table. You can update one or multiple columns using the SET clause.

Syntax

UPDATE table_name
SET column_name = value
WHERE condition;

The WHERE clause specifies which rows should be updated. Without it, every row in the table will be modified.

Example 1

Update the grade of students whose grade is A. 

UPDATE student
SET grade = "S"
WHERE grade = "A";

Example 2

Increase the marks of every student by one. 

UPDATE student
SET marks = marks + 1;

Example Table

Before After
Marks = 89 Marks = 90
Marks = 76 Marks = 77

DELETE Statement

The DELETE statement removes records from a table. Unlike TRUNCATE, only the rows matching the specified condition are deleted.

Syntax

DELETE FROM table_name
WHERE condition;

Example

Delete students whose marks are below 35. 

DELETE FROM student
WHERE marks < 35;

DELETE without WHERE

If the WHERE clause is omitted, every row in the table is deleted. The table structure remains unchanged. 

DELETE FROM student;

UPDATE vs DELETE

Statement Purpose
UPDATE Modify existing records.
DELETE Remove selected records.

Cascading Foreign Keys

Foreign keys maintain relationships between two tables. Cascading automatically updates or removes related records, keeping both tables synchronized.

Example

CREATE TABLE student (

    id INT PRIMARY KEY,

    courseid INT,

    FOREIGN KEY(courseid)
    REFERENCES course(id)

    ON DELETE CASCADE

    ON UPDATE CASCADE

);

ON DELETE CASCADE

When a record in the parent table is deleted, all related rows in the child table are automatically deleted.

Example

WHERE id = 101;

ON UPDATE CASCADE

If the referenced primary key changes, all matching foreign keys are updated automatically.

Example

UPDATE course
SET id = 201
WHERE id = 101;

Every student whose courseid was 101 automatically becomes 201.

Advantages of Cascading

  • Maintains referential integrity.
  • Prevents orphan records.
  • Automatically updates related tables.
  • Reduces manual database maintenance.

SQL Joins

SQL Joins combine data from two or more tables based on a related column. They are one of the most important concepts in relational databases because they allow information stored in separate tables to be retrieved together.

INNER JOIN

The INNER JOIN returns only the rows that have matching values in both tables. 

SELECT columns
FROM tableA
INNER JOIN tableB
ON tableA.column = tableB.column;

Only records existing in both tables are included in the result.

LEFT JOIN

The LEFT JOIN returns all records from the left table and only the matching rows from the right table. If no match exists, NULL values are returned for the right table. 

SELECT columns
FROM tableA
LEFT JOIN tableB
ON tableA.column = tableB.column;

RIGHT JOIN

The RIGHT JOIN returns every row from the right table and only the matching rows from the left table. If no matching record exists, NULL values are returned for the left table. 

SELECT columns
FROM tableA
RIGHT JOIN tableB
ON tableA.column = tableB.column;

FULL OUTER JOIN (Using UNION)

MySQL does not directly support a FULL OUTER JOIN. Instead, it can be achieved by combining a LEFT JOIN and a RIGHT JOIN using the UNION operator. 

SELECT columns
FROM tableA AS A
LEFT JOIN tableB AS B
ON A.id = B.id

UNION

SELECT columns
FROM tableA AS A
RIGHT JOIN tableB AS B
ON A.id = B.id;

LEFT EXCLUSIVE JOIN

Returns only the rows that exist in the left table but not in the right table. 

SELECT columns
FROM tableA
LEFT JOIN tableB
ON tableA.id = tableB.id
WHERE tableB.id IS NULL;

RIGHT EXCLUSIVE JOIN

Returns only the rows that exist in the right table but not in the left table. 

SELECT columns
FROM tableA
RIGHT JOIN tableB
ON tableA.id = tableB.id
WHERE tableA.id IS NULL;

SELF JOIN

A SELF JOIN joins a table with itself. It is useful when comparing rows within the same table, such as employees and managers. 

SELECT columns
FROM employee AS A
JOIN employee AS B
ON A.manager_id = B.employee_id;

JOIN Summary

Join Returns
INNER JOIN Matching rows from both tables.
LEFT JOIN All left rows + matching right rows.
RIGHT JOIN All right rows + matching left rows.
FULL JOIN All rows from both tables.
SELF JOIN Join a table with itself.

UNION

The UNION operator combines the results of two SELECT queries. Duplicate rows are automatically removed. 

SELECT columns
FROM tableA

UNION

SELECT columns
FROM tableB;

UNION ALL

Unlike UNION, UNION ALL keeps duplicate rows, making it slightly faster. 

SELECT columns
FROM tableA

UNION ALL

SELECT columns
FROM tableB;

UNION vs UNION ALL

UNION UNION ALL
Removes duplicates. Keeps duplicates.
Slightly slower. Faster.

SQL Subqueries

A Subquery is a query written inside another SQL query. The inner query executes first, and its result is used by the outer query.

Syntax

SELECT column_name
FROM table_name
WHERE column_name OPERATOR
(
    SELECT column_name
    FROM table_name
);

Example

Display students whose marks are greater than the class average. 

SELECT name, marks
FROM student
WHERE marks >

(
    SELECT AVG(marks)
    FROM student
);

Additional SQL Operators

The modulo operator can be used to filter even or odd values, while IN compares a value against multiple options. 

-- Even Numbers

SELECT *
FROM table_name
WHERE id % 2 = 0;

-- Values From List

SELECT *
FROM table_name
WHERE id IN (102,104,106);

VIEW

A VIEW is a virtual table created from the result of a SQL query. It stores only the query, not the actual data. Whenever the view is accessed, the query executes automatically.

Create View

CREATE VIEW view1 AS

SELECT rollno,
       name

FROM student;

Using a View

SELECT *
FROM view1;

Advantages of Views

  • Simplifies complex queries.
  • Improves security by exposing only required columns.
  • Provides reusable query logic.
  • Makes reporting easier.

Key Takeaways

  • Use JOINS to combine data from multiple tables.
  • Use UNION to combine the results of multiple SELECT queries.
  • Use Subqueries when one query depends on another.
  • Use Views to simplify frequently used queries.
  • Choose the appropriate JOIN based on the data you need.
